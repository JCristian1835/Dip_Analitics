# Diplomado en Data Analytics: cuaderno de estudio

Temario, teoría, ejercicios y recomendaciones de estudio de cada clase, construidos a partir de las transcripciones.

**Empieza aquí:** [temario general](temario-general.md)

## Qué hay en cada clase

Cada carpeta de [`clases/`](clases/) tiene:

| Archivo | Para qué sirve |
| --- | --- |
| `temario.md` | Qué se vio en la clase y qué tareas dejaron |
| `teoria.md` | La teoría explicada desde cero |
| `ejercicios.md` | Práctica de menos a más, sin respuestas |
| `soluciones.md` | Respuestas verificadas y explicadas |
| `como-aprenderlo.md` | Orden de estudio, errores comunes y recursos |

## Cómo leer la teoría

- 🎙️ **Salió de la clase:** aparece en la transcripción.
- ➕ **Complemento:** se agregó para entender mejor el tema. No lo dijo necesariamente el profesor, así que confírmalo con él si es para una entrega.

## Cómo correr el código

```bash
python -m pip install -r requirements.txt
```

```bash
python clases/clase-01/soluciones.py
```

## Privacidad

Este repositorio es público. Las transcripciones traen nombres de estudiantes, así que se guardan solo en la carpeta local `transcripciones/`, que Git ignora. Los datos de los ejercicios son ficticios.
