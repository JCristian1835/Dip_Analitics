# Instrucciones para construir el material de cada clase

Este repositorio es **público**. Es el cuaderno de estudio del Diplomado en Data Analytics.

## Flujo por cada transcripción nueva

1. Guardar la transcripción en `transcripciones/clase-NN.txt`. Esa carpeta no se sube.
2. Revisar qué tramos de tiempo cubre. Si faltan partes, decirlo en `temario.md`.
3. Crear `clases/clase-NN/` con los archivos de abajo.
4. Actualizar la tabla de `temario-general.md`.
5. Correr `soluciones.py`, si existe, y copiar sus resultados reales a `soluciones.md`.

## Archivos de cada clase

| Archivo | Contenido |
| --- | --- |
| `temario.md` | Qué se vio, tramos que cubre la transcripción, tareas y fechas |
| `teoria.md` | La teoría explicada desde cero, con ejemplos |
| `ejercicios.md` | Práctica de menos a más, sin respuestas |
| `soluciones.md` | Respuestas verificadas y explicadas |
| `como-aprenderlo.md` | Orden de estudio, errores comunes y recursos |

## Reglas

- **Privacidad:** nunca publicar transcripciones, nombres de estudiantes ni datos reales de un negocio o una persona. Usar "un compañero" y "el profesor". Los datos de práctica son ficticios.
- **Separar las fuentes:** marcar con 🎙️ lo que salió de la clase y con ➕ lo que se agregó para completar. No atribuirle al profesor algo que no aparece en la transcripción.
- **Transcripción automática:** tiene errores. Si una palabra es dudosa, escribirlo así en vez de adivinar.
- **Verificar:** ningún resultado numérico va en `soluciones.md` sin haber corrido el cálculo. Comprobar que cada enlace de recursos abre antes de recomendarlo.
- **Nivel:** español, para principiantes. Primero la idea con un ejemplo, después la fórmula o el código.
